## Environment and reproducible commands

Local validation uses macOS arm64, Python 3.12.9, CPU execution and the dependency
snapshot in `constraints/python312-tested.txt`. See the
[maintenance guide](maintenance.md) for installation and source checks.

```bash
python -m pytest -q
python tests/comparisons/run_all_comparisons.py --tests-only
python -m pip check
python -m compileall -q src scripts vendor/scraw_inductive/src vendor/scraw_dedicated/src
python -m build
git diff --check
```

The wheel is installed in a separate environment. The integration tests and
package metadata tests are copied outside the repository and run with
`python -I -m pytest`; imports are checked to originate from `site-packages`.
The development environment remains an editable installation.

## Scope and remaining release work

Passing tests demonstrate the exercised behavior; they cannot guarantee that
all datasets, hardware and parameter combinations are bug-free. The complete
biological report campaign, GPU/MPS paths, optional LLM stack and optional
external backend environments were not run. Six original-source comparison
checks are skipped because their required author source modules are unavailable.
These skipped checks do not establish numerical equivalence.

The GitHub workflow completed successfully on both Ubuntu and macOS for the
published hardening branch. It tested the source checkout and the installed
wheel on both systems. No changes were pushed directly to main.

Large checkpoints and historical artifacts are retained so replay remains
possible. The wheel and source distribution exclude those large experiment
bundles. The repository's Git history has not been rewritten. A future archive
migration must verify downloads, checksums and replay before removing Git copies.

The project-wide license and third-party redistribution permissions require a
rights-holder decision and provenance review; see [THIRD_PARTY.md](../../THIRD_PARTY.md).
The two large legacy GUI modules remain and should be decomposed incrementally
under regression tests. These items remain release work, separate from the
validated installation and correctness fixes.
